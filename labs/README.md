# Technical Drawing with AutoCAD Electrical — Hands-On Labs

**WSQ Course Code:** TGS-2023037466  ·  **Conducted by:** Tertiary Infotech Academy Pte Ltd (UEN 201200696W)  ·  **Version v6.0**

Each lab lives in its own folder with the instructions as Markdown (`.md`) and PDF, plus the starter AutoCAD DWG file(s) used in the lab. Complete the labs in order — they build on each other within each topic.

## Topic 01 — Introduction to Technical Drawing Using AutoCAD Electrical

- [Lab 1: Set Up a New AutoCAD Electrical Drawing](lab-01-setting-up-a-new-drawing/lab-01-setting-up-a-new-drawing.md) — A correctly configured metric drawing sheet, saved as a reusable baseline for the rest of the course.
- [Lab 2: Create a Project with Project Manager](lab-02-create-a-project-with-project-manager/lab-02-create-a-project-with-project-manager.md) — A working .wdp project containing the supplied power and lighting plan drawings plus a title block, in the correct sheet order.

## Topic 02 — Analysing Technical Drawings

- [Lab 3: Build Circuits with Circuit Builder](lab-03-build-circuits-with-circuit-builder/lab-03-build-circuits-with-circuit-builder.md) — A schematic sheet containing a Circuit Builder motor circuit plus a saved, reusable circuit block.
- [Lab 4: Insert Wires, Wire Numbers and Terminals](lab-04-insert-wires-and-wire-numbers/lab-04-insert-wires-and-wire-numbers.md) — A correctly wired and wire-numbered circuit with terminals, matching the drawing's wire-number specification.
- [Lab 5: Cross-Reference and Surf a Drawing Set](lab-05-cross-reference-and-surf/lab-05-cross-reference-and-surf.md) — A cross-referenced two-sheet circuit you can navigate with Surfer, plus a Mark/Verify change report.

## Topic 03 — Reviewing Technical Drawings for Strategic Relevance and Standard Compliance

- [Lab 6: Create a Panel Layout with Footprints](lab-06-create-a-panel-layout/lab-06-create-a-panel-layout.md) — A panel layout drawing with footprints placed from the schematic list, a nameplate, item numbers and balloons.
- [Lab 7: Generate Reports and Part Lists](lab-07-generate-reports-and-part-lists/lab-07-generate-reports-and-part-lists.md) — A BOM table placed on the drawing plus a saved .SET format file and a CSV export of the report.
- [Lab 8: Plot and Publish the Project to PDF](lab-08-plot-and-publish-to-pdf/lab-08-plot-and-publish-to-pdf.md) — An A3 PDF plot of one sheet and a hyperlinked multi-sheet PDF of the whole project.
