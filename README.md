A 2-day (16-hour) SkillsFuture WSQ course on producing, analysing and reviewing electrical
technical drawings with the AutoCAD Electrical toolset — from the user interface and
project-based drawing management through schematic circuits, wiring and cross-referencing,
to panel layouts, part-list reports, custom symbols and submission-ready PDF publishing.

## About the course

This practical course uses connected AutoCAD Electrical project, schematic, panel, report and
publishing workflows so learners can produce, analyse and review submission-ready electrical
technical drawings.

## Learning outcomes

- **LO1** — Devise metrics for technical drawings production using AutoCAD Electrical and formulate solutions for encountered development problems. *(K1, K2, A1, A2)*
- **LO2** — Analyse technical drawings with AutoCAD Electrical to determine construction needs while reviewing for accuracy and adherence to specifications. *(K3, K4, A3, A4)*
- **LO3** — Review technical drawings for relevance to organisation's strategies and ensure their conformance to submission standards. *(K5, K6, A5, A6)*

current installed libraries when prompted.

## Requirements

- **AutoCAD Electrical** (the Electrical toolset included with AutoCAD) — free 30-day trial or education licence from [autodesk.com](https://www.autodesk.com/). Windows required for the Electrical toolset.
- Basic computer operation skills; no prior AutoCAD experience assumed.

## Assessment

- **Written Assessment (WA)** — Short-Answer Questions (SAQ), 1 hour, open book *(K1–K6)*
- **Practical Performance (PP)** — hands-on AutoCAD Electrical tasks, 1 hour, open book *(A1–A6)*

Assessment papers are confidential and are **not** in this repository.

## Public package and distribution boundary

This repository publishes the current trainer deck, learner-facing PDF/Markdown resources, and
open-source DWG starters. It excludes assessments, answer keys, credentials, source references,
private build tooling, QA renders, archives, and controlled Autodesk project packages. Those items
remain in the appropriate trainer or controlled course-delivery locations.
